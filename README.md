# Indee BDD Project

This project automates video playback and controls on the Indee demo site using **Behave BDD + Selenium + POM**.

## Features
- Login with PIN
- Navigate to Test Automation Project
- Switch between Details & Videos tabs
- Play, pause, resume video
- Continue Watching
- Adjust volume (50%)
- Change resolution (480p → 720p)
- Pause & exit project
- Logout
